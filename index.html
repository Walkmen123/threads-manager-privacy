Privacy Policy

Taxi NL Threads Manager
Last updated: November 15, 2026

1. About the application

Taxi NL Threads Manager is a private, owner-operated tool used to manage the owner's Threads account and related content. It is not offered as a public service and does not provide account registration for other users.

2. Information processed

When authorized by the account owner, the application may process Threads account identifiers, public profile information, post content, post identifiers, public search results, replies, and post performance metrics, depending on the permissions enabled. The application also processes the owner's Telegram commands and approval decisions.

3. Purpose and use

Information is used to draft and publish posts, find relevant public conversations, prepare and manage replies, review publication status, and analyze content performance. Publication and replies are intended to occur only with the account owner's authorization.

4. Storage and security

The application is designed to run locally on the owner's computer. Drafts, post status, and related records may be stored in a local SQLite database. API credentials are configured locally and should not be published in source repositories or shared with third parties. Reasonable precautions are taken to limit access, but no system can guarantee absolute security.

5. Sharing and third-party services

The application communicates with Meta's Threads API and Telegram to provide its functions. Data is processed by those services under their respective policies. The application does not sell personal information or operate an advertising-data marketplace.

6. Retention and deletion

Locally stored records are retained for as long as needed to operate the tool or until the owner deletes them. The owner may stop using the tool, revoke its Threads authorization, and delete local configuration and database files. Content already published on Threads is managed separately through Threads.

7. Other users' public content

Public Threads posts may be retrieved for contextual review when the Threads API permits it. The application is not intended to collect private messages or build profiles of unrelated individuals.

8. Changes

This policy may be updated if the application's functionality or data handling changes. The latest version will be available at this page.
